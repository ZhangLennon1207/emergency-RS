# Examples

The files in this directory are sanitized interface examples.

They do not contain:

- real training data;
- final-test samples;
- model weights;
- real local machine paths;
- credentials.

`example_request.json` demonstrates the Agent3 -> Agent4 input contract.

`example_asset_manifest.json` demonstrates the optional visual-evidence
binding contract.

Real paths must be supplied by the deployment environment.
