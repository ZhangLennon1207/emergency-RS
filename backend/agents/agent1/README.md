# Agent1：时空视觉证据感知

负责人将建筑、道路、损伤识别和量化评估代码提交到本目录。

## 输入

- 灾前影像
- 灾后影像
- 任务工作目录和模型配置

## 主要输出

- 建筑与损伤Mask
- 建筑实例和损伤等级统计
- 道路影响结果
- 融合图、叠加图和对比图
- 人工复核标志与风险等级
- 可供Agent2、Agent3使用的结构化证据

## 提交要求

1. 原始代码放入 `src/`。
2. 在 `adapter.py` 中接入统一 `run()`。
3. 更新 `requirements.txt`，只写本模块实际使用的依赖。
4. 在 `examples/` 放一个小型JSON输出，不提交遥感数据集。
5. 在 `tests/` 至少提供一个不加载大模型的格式测试。

正式字段以 `docs/api-contract.md` 的 `visual_evidence` 为准。
